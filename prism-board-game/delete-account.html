PRISM Board Game 계정 및 데이터 삭제

PRISM Board Game(개발자: 프리즘(Prism)) 계정과 관련 데이터의 삭제를 요청하는 방법입니다.

앱에서 바로 삭제하기

  1. 앱 하단의 오늘 탭에서 오른쪽 위 계정 아이콘을 누릅니다.
  2. 계정 삭제를 누르고, 확인 칸에 “삭제”를 입력한 뒤 영구 삭제를 누릅니다.
  3. 계정과 아래 데이터가 즉시 삭제되고 로그아웃됩니다.

앱을 쓸 수 없을 때: 메일로 요청하기

  1. 앱에 로그인할 때 사용한 Google 계정의 이메일로 contact@prism-devs.com에 메일을 보내 주세요.
  2. 제목에 “PRISM Board Game 계정 삭제 요청”이라고 적어 주세요. 본인 확인을 위해 가입한 이메일 주소에서 보낸 요청만 처리합니다.
  3. 요청을 확인한 뒤 30일 이내에 삭제하고, 완료되면 메일로 알려 드립니다.

삭제되는 데이터

  • 계정 정보: 이메일 주소, 이름, 프로필 사진 URL, Google 계정 식별자
  • 보드게임 컬렉션: 등록한 게임, 보유 상태, 즐겨찾기, 평점, 보관 위치, 메모
  • 플레이 기록: 일시, 플레이 시간, 장소, 메모, 참가자 이름, 점수, 승자

삭제한 데이터는 복구할 수 없으며, 별도로 보관하는 데이터는 없습니다. 모든 사용자가 함께 보는 게임 카탈로그 정보(게임 이름, 인원, 시간 등)는 개인정보가 아니므로 삭제 대상이 아닙니다.

계정은 유지하고 일부 데이터만 지우려면

컬렉션 항목과 플레이 기록은 앱에서 언제든 직접 삭제할 수 있습니다. 기기에만 저장된 추천 조건과 추천 제외 목록은 앱을 삭제하면 함께 지워집니다.

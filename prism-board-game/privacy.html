PRISM Board Game 개인정보 처리방침

PRISM Board Game(이하 “앱”)은 보드게임 컬렉션 관리, 플레이 기록, 오늘 할 보드게임 추천 기능을 제공합니다. 앱 개발자 프리즘(Prism, 이하 “개발자”)은 이 기능에 꼭 필요한 정보만 처리합니다.

시행일: 2026년 9월 28일

1. 처리하는 정보

구분항목목적
계정 정보Google 계정의 이메일 주소, 이름, 프로필 사진 URL, Google 계정 식별자로그인, 사용자 식별, 본인 데이터 연결
보드게임 컬렉션등록한 게임, 보유 상태(소유·위시리스트·대여 등), 즐겨찾기, 평점, 보관 위치, 메모컬렉션 관리, 오늘의 보드게임 추천
플레이 기록플레이한 게임, 일시, 플레이 시간, 장소, 메모, 참가자 이름, 점수, 승자기록·통계 제공, 최근 플레이를 반영한 추천
기기에만 저장마지막 추천 조건, 추천에서 제외한 게임 목록, 이미지 캐시앱 사용 편의. 개발자 서버로 전송되지 않습니다.

플레이 기록의 참가자 이름은 사용자가 직접 입력하는 값입니다. 함께 플레이한 분의 실명 대신 별명을 쓰거나, 그분의 동의를 받아 입력해 주세요.

2. 수집하지 않는 정보

전화번호, 주소, 정확한 위치, 연락처, 사진·카메라, 마이크, 결제 정보, 건강 정보는 요청하지 않습니다. 광고, 분석, 크래시 수집 SDK를 사용하지 않으며 광고 식별자도 사용하지 않습니다.

3. 처리 위탁과 외부 서비스

  • Supabase — 계정 인증과 데이터 저장(데이터베이스). 서버 위치: 대한민국 서울(AWS ap-northeast-2).
  • Google 로그인 — Google 계정으로 로그인할 때 Google이 인증을 처리하고, 앱은 로그인 확인용 토큰과 위 1항의 계정 정보를 받습니다.
  • 게임 이미지 — 게임 표지 이미지는 BoardGameGeek 이미지 서버에서 불러옵니다. 이때 해당 서버는 이미지 요청에 포함된 IP 주소 등 일반적인 접속 정보를 받을 수 있습니다.

개발자는 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.

4. 보관 기간과 삭제

계정과 앱 데이터는 사용자가 계정 삭제를 요청할 때까지 보관합니다. 컬렉션 항목과 플레이 기록은 앱에서 언제든 직접 수정·삭제할 수 있습니다.

계정과 모든 데이터는 앱의 계정 → 계정 삭제에서 즉시 삭제할 수 있습니다. 앱을 쓸 수 없을 때는 계정 및 데이터 삭제 안내에 따라 메일로 요청할 수 있으며, 요청을 확인한 뒤 30일 이내에 삭제합니다. 기기에만 저장된 정보는 앱을 삭제하면 함께 지워집니다.

5. 안전성 확보 조치

모든 통신은 HTTPS로 암호화됩니다. 데이터베이스는 행 단위 접근 제어(RLS)를 적용해 로그인한 사용자 본인의 컬렉션과 플레이 기록만 조회·수정할 수 있습니다.
